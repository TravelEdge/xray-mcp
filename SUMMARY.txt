HOW TO USE WITH YOUR HELM DEPLOYMENT
================================================================================

Your xray-mcp server is running. Here's how to connect Claude Desktop:

OPTION 1: Fully-Shared Mode (Server uses its own credentials)
  
  Configuration file:
  - macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  - Windows: %APPDATA%\Claude\claude_desktop_config.json
  - Cursor: ~/.cursor/mcp.json or .cursor/mcp.json

  Content:
  {
    "mcpServers": {
      "xray": {
        "transport": "http",
        "url": "https://xray-mcp.yourcompany.com/mcp",
        "autoApprove": ["xray_get_*", "xray_list_*"]
      }
    }
  }

  Then restart Claude Desktop.

OPTION 2: Strict/Shared-Reads Mode (Pass your credentials in headers)

  Content:
  {
    "mcpServers": {
      "xray": {
        "transport": "http",
        "url": "https://xray-mcp.yourcompany.com/mcp",
        "headers": {
          "X-Xray-Client-Id": "your-client-id",
          "X-Xray-Client-Secret": "your-client-secret"
        },
        "autoApprove": ["xray_get_*", "xray_list_*"]
      }
    }
  }

  Then restart Claude Desktop.

================================================================================
VERIFY YOUR DEPLOYMENT
================================================================================

Test your server:

  # Liveness check (always passes)
  curl http://your-helm-server:3000/healthz
  → { "status": "ok", "transport": "http" }

  # Readiness check (verifies Xray connectivity)
  curl http://your-helm-server:3000/readyz
  → { "status": "ready", "xray": "reachable" }

If readiness shows "not configured", your server doesn't have Xray credentials.
Check your Helm values: xray.credentialMode and credentials.
